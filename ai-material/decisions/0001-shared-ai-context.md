# Shared AI Context System

Decision:
Use `ai-material/` as the shared AI memory folder.

Reason:
The team uses multiple AI tools, so context must be portable, concise, and searchable.

Consequences:
- AI tools must read INDEX.md before working.
- Sessions must be summarized.
- Reusable knowledge must be promoted into curated folders.
- Token efficiency is required.
