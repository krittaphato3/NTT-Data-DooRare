# Guidelines

Token-efficient, high-quality use of AI in this repo.

## Loading rules

- Read AGENTS.md, GUIDELINES.md, and INDEX.md first.
- Do not read all files in ai-material.
- Use INDEX.md to find relevant paths.
- Open only files whose title, tags, or summary match the current task.
- Prefer `context/current-task.md`, `context/current-status.md`, and `context/architecture.md` for broad context.
- Read full session files only if no curated file has the answer.
- Do not read sessions older than 30 days unless explicitly needed.

## Token-saving rules

- Do not paste full transcripts.
- Do not store large code blocks unless absolutely necessary.
- Prefer file paths plus a short explanation over full code.
- Prefer bullets over paragraphs.
- Prefer updating existing files over creating duplicates.
- Keep INDEX.md summaries under 12 words.
- Keep session notes between 150 and 250 words.
- Only promote repeated or reusable knowledge into curated folders.

## Quality rules

- Follow `context/conventions.md`.
- Do not make unrelated refactors.
- Do not leave broken code.
- Update `context/current-task.md` if task state changes.
- Record decisions if a meaningful choice is made.
- Record errors and fixes if they are likely to happen again.

## Loading levels

- Level 0: AGENTS.md + GUIDELINES.md + INDEX.md
- Level 1: context/current-task.md + context/current-status.md + context/architecture.md
- Level 2: only relevant decisions/skills/errors/prompts
- Level 3: full session file only as last resort

## When to stop reading

Stop once you have enough to act. More reading is not a substitute for deciding.
