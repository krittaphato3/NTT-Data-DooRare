# Bootstrap prompt

Use this prompt when starting a new AI session in this repo:

1. Read AGENTS.md
2. Read ai-material/GUIDELINES.md
3. Read ai-material/INDEX.md
4. Read ai-material/context/current-task.md
5. Read ai-material/context/current-status.md
6. Read ai-material/context/architecture.md only if you need project-wide context
7. Read only the curated files that match the task: decisions, skills, errors, prompts
8. Do not read all session files
9. Follow ai-material/context/conventions.md
10. Use ai-material/context/runbook.md for commands
11. Check ai-material/context/quality-checklist.md before saying work is done

When done, update:

- ai-material/sessions/<today-session>.md
- ai-material/INDEX.md if needed
- any curated file if reusable knowledge appeared

Keep notes short, scannable, and token-efficient.
